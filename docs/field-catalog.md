# Каталог полей

> **Как использовать.** Положите этот файл в репозиторий как `docs/field-catalog.md`.
> Это общий справочник для фич 02 (эталон), 05 (извлечение), 06 (проверки),
> 07 (фильтры поиска) и 10 (ответы по таблице). Технический контекст ссылается на него.
>
> Каталог — предложение. Его должны поправить люди, которые работают с договорами.
> Любое изменение каталога требует обновить эталон и повторить замеры.

## Допущения

- У договора две стороны: генеральный подрядчик и субподрядчик.
- Договоры на русском языке и не связаны между собой.
- Значения, записанные формулой, хранятся дважды: текстом как в договоре и числом
  там, где число однозначно. Если число неоднозначно, числовое поле остаётся пустым.

## Виды значений

| Вид | Как сравнивается с эталоном |
|---|---|
| идентификатор | точное совпадение после удаления пробелов и приведения дефисов, кавычек, регистра |
| дата | совпадение после приведения к виду ГГГГ-ММ-ДД |
| сумма | совпадение чисел |
| процент | совпадение чисел |
| число | совпадение чисел |
| наименование | совпадение после приведения регистра, кавычек, пробелов, «ё» |
| выбор из списка | точное совпадение с одним из вариантов |
| свободный текст | вручную |
| список | вручную |

## Поля, пригодные для фильтров

Эти поля используются как фильтры в поиске (фича 08) и в ответах по таблице
(фича 10): `contract_number`, `signing_date`, `contract_type`, `contractor_name`,
`contractor_bin`, `subcontractor_name`, `subcontractor_bin`, `total_amount`,
`currency`, `vat_included`, `advance_share`, `start_date`, `end_date`,
`completion_deadline_date`, `delay_penalty_rate`, `penalty_cap`, `warranty_months`.

Поля со свободным текстом как фильтры не используются; вопросы по ним идут
в поиск по тексту.
