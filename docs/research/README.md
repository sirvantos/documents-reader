# Исследование: справочные материалы

Обзор методов чтения, извлечения, поиска и ответов по документам, подготовленный
до начала проекта (ноябрь 2026).

**Это не решения проекта.** Здесь разобраны и варианты, которые сознательно
не выбраны: распознавание сканов, облачные сервисы, другие модели и инструменты.

Обязательны только:

- `.specify/memory/constitution.md` — принципы и ограничения;
- `docs/tech-context.md` — стек и технические решения;
- `docs/field-catalog.md` — перечень полей.

Если материал отсюда противоречит этим файлам, действуют они. Использовать
исследование можно для обоснования выбора внутри плана фичи, например при
сравнении библиотек.

Встроенные схемы при выгрузке в Markdown заменены текстовой заглушкой.
