# Contract: команды `docreader check …`

Все команды: `DOCREADER_DATA_DIR` обязателен; вывод — только числа, идентификаторы, коды
и названия полей, правил, статусов и причин (FR-013); `--json` — те же данные. Код 0 —
успех, 1 — ошибка пользователя (причина в stderr), 2 — среда. Моделей не вызывают.

## `docreader check [ID…] [--all] [--again] [--json]`

Проверки и статусы шести полей. Без `ID` и `--all` — договоры с извлечением, у которых
проверок нет или они устарели (research R-7); `--again` — пересчитать и неустаревшие.
Договор без извлечения пропускается с причиной.

```
D-0001  проверено  принято 5, требует просмотра 1, отклонено 0, не найдено 0
        нарушено: amount_words (сумма с НДС)
D-0002  проверено  принято 6
D-0003  пропущено  нет извлечения — docreader extract D-0003
Итого: проверено 2, пропущено 1; полей: принято 11, требует просмотра 1, отклонено 0,
не найдено 0 (запуск 120, правила 06.1)
```

## `docreader check queue [ID…] [--out ПАПКА] [--json]`

Страница очереди в `checks/queue-<сборка>/` папки данных (research R-9; `--out` — папка
внутри папки данных, иначе код 1). Карточки — поля «требует просмотра» и «отклонено»
неустаревших договоров.

```
Очередь: checks/queue-20261128-101500/index.html
  карточек 7: требует просмотра 6, отклонено 1; значение системы изменилось 0
  по полям: amount_with_vat 3, amount_without_vat 2, contract_number 1, contract_end_date 1
  договоров с устаревшими проверками: 0 (сначала docreader check)
```

## `docreader check load ФАЙЛ [--json]`

Ответы страницы (`check-review-<сборка>.json`, contracts/files.md). Сборка ищется по
`build` в `checks/queue-…/cards.json`; нет — код 1, ничего не меняется.

```
Решения: ответы страницы очереди (7 карточек)
  принято 6: подтверждено 3, исправлено 2, в договоре нет 1; пропущено 1
  ошибок вида 1: карточка D-0012/amount_with_vat — значение не приводится к сумме
  не применено 0 (договора или поля больше нет)
  статусы пересчитаны у 6 полей
```

## `docreader check report [--label МЕТКА] [--json]`

Польза правил по эталону фичи 02 (research R-10); запись таблицы результатов этапа
`checks`. Без эталона — код 1. Договоры с устаревшими проверками — вне отчёта, число
называется.

```
Польза правил: запись 40 «правила 06.1» (правила 06.1), версия эталона 76fb2999493e
  пар 234: верных 234, неверных 0; в очереди: неверных 0 из 0, верных 3 из 234 (1%)
  правило            сработало  на неверных
  amount_words               1            0
  vat_consistent             2            0
  …
  договоров вне отчёта: без эталона 17, проверки устарели 0
  разбор: eval/checks-40-20261128-102000.csv
```

`eval show 40`, `eval compare`, `eval export` (фича 02) раскрывают и сравнивают запись.
