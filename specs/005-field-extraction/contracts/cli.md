# CLI: извлечение полей (фича 05)

Команды устроены по образцу `parse` и `outline` [фичи 04](../../004-structure-parsing/contracts/cli.md):
переменные окружения, `--json`, коды выхода (0 — успех, 1 — ошибка пользователя,
2 — ошибка окружения, 130 — прервано) те же. Решения — в [research.md](../research.md).

## `docreader extract [ID…] [--all] [--label МЕТКА] [--json]`

Заполняет шесть полей прототипа у разобранных договоров.

- Без аргументов — доступные договоры, у которых этап `extraction` в `pending`
  или `failed`. `--all` — все доступные. `ID…` — указанные; `--all` вместе с ID —
  ошибка пользователя.
- Доступен договор, у которого разбор `done` или `needs_review` и получен по текущему
  тексту (R-9). Указанный недоступный договор не трогается и попадает в вывод
  со строкой «пропущен» и причиной («не разобран — выполните docreader parse D-0003»;
  «разбор устарел — выполните docreader parse D-0003»).
- Нечего извлекать — «Нечего извлекать: поля всех договоров заполнены (заново:
  docreader extract --all)», код 0.
- До первого договора проверяется сервер модели. Нет ответа — сообщение
  «Модель недоступна по адресу http://127.0.0.1:8080/v1 — запустите сервер модели»,
  код 2, ни один договор не тронут. Так же при `DOCREADER_FORBID_MODELS`
  («На этой машине языковая модель не запускается (DOCREADER_FORBID_MODELS)»).
- Обрыв или тайм-аут на договоре — команда останавливается (код 2): текущий договор
  не тронут, уже записанные остаются; вывод показывает сделанное и строку
  «Остановлено: модель не ответила на D-0004 (тайм-аут 1800 с)».

Текстовый вывод — строка на договор и итог; ни значений, ни цитат, ни текста
договоров (FR-015):

```text
D-0001  готово             найдено 5, не найдено 1 (цена с НДС), отклонено 0
D-0002  требует просмотра  найдено 4, не найдено 1 (дата окончания), отклонено 1 (цена без НДС) — отклонено: цена без НДС — значение не подтверждено цитатой
D-0003  пропущен           не разобран — выполните docreader parse D-0003
D-0004  ошибка             ответ модели не по форме после 2 повторов
Итого: извлечено 2, требует просмотра 1, ошибок 1, пропущено 1; полей найдено 9, не найдено 2, отклонено 1 (запуск 61, модель qwen3.6-27b-4bit, подсказка 05.1)
```

`--json`:

```json
{
  "run_id": 61,
  "model": "qwen3.6-27b-4bit",
  "prompt_version": "05.1",
  "documents": [
    {"document_id": "D-0001", "state": "done", "reason": null,
     "found": 5, "not_found": 1, "rejected": 0,
     "not_found_fields": ["amount_with_vat"], "rejected_fields": [],
     "seconds": 212.4}
  ],
  "skipped": [{"document_id": "D-0003", "reason": "не разобран — выполните docreader parse D-0003"}],
  "totals": {"extracted": 2, "needs_review": 1, "failed": 1, "skipped": 1,
             "fields_found": 9, "fields_not_found": 2, "fields_rejected": 1},
  "interrupted": false,
  "stopped": null
}
```

`stopped` — `null` или `{"document_id", "reason"}` при остановке из-за модели.
`seconds` — время запроса к модели по договору (замер Б3, SC-004).

Причины `failed`: «ответ модели не по форме после N повторов», «текст слишком длинный:
N знаков при пределе M», «ошибка извлечения: <тип исключения>» (текст исключения
не выводится и не сохраняется). Виды причин `needs_review` — research R-8.

## `docreader fields ID [--json]`

Поля одного договора (история 4). **Выводит значения и цитаты — текст договора.**

```text
D-0001 — извлечение от 2026-11-26 (запуск 61, модель qwen3.6-27b-4bit, подсказка 05.1), требует просмотра
  отклонено: цена без НДС — значение не подтверждено цитатой

номер договора      найдено     ДП-17/2026  (как в тексте: «№ ДП-17/2026»)
                                D-0001/преамбула, стр. 1
                                «ДОГОВОР ПОДРЯДА № ДП-17/2026»
заказчик            найдено     ООО "Альфа"  (как в тексте: «ООО «Альфа»»)
                                D-0001/преамбула, стр. 1
                                «… (далее — ООО «Альфа»), в лице …»
цена без НДС        отклонено   значение не подтверждено цитатой
                                модель: «1 000 000 рублей», пункт 2.1
                                цитата модели: «…»
цена с НДС          не найдено
…
```

- По каждому из шести полей в порядке каталога: результат; для `found` — приведённое
  значение, значение как в тексте, идентификатор пункта, страница и цитата (одной
  строкой, переносы → пробел); пометка `[низкое качество распознавания]`, если
  страница цитаты с флагом; для `rejected` — причина, предложенное моделью значение,
  цитата и пункт модели; для `failed` — причина.
- Шапка: запуск, модель, версия подсказки, состояние этапа и причина (FR-012).
- Ошибки (код 1, сообщение по-русски с подсказкой): неизвестный договор; поля
  не извлекались («Поля D-0001 не извлекались — выполните docreader extract D-0001»);
  поля устарели («Поля устарели: текст изменён — выполните docreader extract D-0001»).

`--json`: `{"document_id", "state", "reason", "run_id", "model", "prompt_version",
"fields": [{"field", "label", "result", "value_text", "value_normalized", "quote",
"quote_start", "quote_end", "clause_id", "page", "pages", "low_quality", "reason",
"proposed_value", "proposed_quote", "proposed_clause"}]}`.

## Что можно присылать агенту

Вывод `extract` (текстовый и `--json`): идентификаторы, состояния, названия полей,
числа, номера страниц, причины, секунды. Вывод `fields` содержит значения и цитаты —
на реальных договорах его агенту не присылать (принцип I); на синтетических — можно.
