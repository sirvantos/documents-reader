# CLI: ответ по тексту (фича 09)

Как у `search` ([фича 08](../../007-hybrid-search/contracts/cli.md)): переменные
окружения, `--json`, коды выхода (0 — ответ выведен, 1 — ошибка пользователя или
ошибка ответа модели, 2 — ошибка окружения, 130 — прервано). Решения —
[research.md](../research.md).

## `docreader ask "ВОПРОС" [--document ID] [--passages N] [--json]`

Находит отрывки поиском фичи 08 (слияние и реранкер), отдаёт их языковой модели,
проверяет цитаты ответа и выводит итог. Ничего не пишет в базу (R-11).

- `--document D-0015` — вопрос об одном договоре: поиск только в нём, все ссылки —
  на него; его преамбула всегда показывается модели (R-5).
- `--passages N` — вместо `[answer] passages` (1…`[search] rerank_candidates`).
- Проверки до моделей и вызовы по порядку (R-1, R-7); на первой неудаче — сообщение
  и код:

  | Случай | Сообщение | Код |
  |---|---|---|
  | пустой вопрос | «Пустой вопрос — введите вопрос о договорах» | 1 |
  | `--passages` вне допустимого | «--passages: целое от 1 до 30» | 1 |
  | ошибки области поиска | как у `search` (нет договора, нет отрывков, устарели, индексы пусты) | 1 |
  | нет векторов модели поиска | как у `search` | 2 |
  | языковая модель недоступна / FORBID / адрес не петлевой | как у `extract` (фича 05) | 2 |
  | модель поиска или реранкер недоступны / FORBID | как у `search` | 2 |
  | обрыв или тайм-аут любого вызова модели | как у `extract` / `search` | 2 |
  | первый ответ не по форме после повторов | итог `failed`: «Ошибка ответа модели: ответ не по форме после 3 попыток» + просмотренные пункты | 1 |
  | сервер языковой модели ответил ошибкой HTTP | итог `failed`: «Ошибка ответа модели: сервер модели отклонил запрос: HTTP 400» + просмотренные пункты | 1 |

Сообщения и предупреждения не содержат текста вопроса, отрывков и ответа модели
(FR-009). Сам вывод ответа содержит текст договоров: на реальных договорах его
не присылают агенту.

### Текстовый вывод (образец формы, не замер)

```text
Вопрос в D-0015 — ответ: подтверждено 2 из 3 утверждений, 18,4 с

1. Оплата — в течение 30 дней с даты поставки.
   «Срок оплаты товара составляет 30 дней с даты поставки.»
   D-0015/2.2, стр. 3
2. Неустойка за просрочку — 0,1% за каждый день.
   «За просрочку поставки Поставщик уплачивает неустойку 0,1% за каждый день.»
   D-0015/3.1, стр. 4 (ссылка исправлена: модель указала D-0015/3.2)

Не подтверждено (цитата не найдена):
- Гарантийный срок — один год.

Повтор запроса: цитат не найдено 2, после повтора 1

Просмотрено (9):
  1. D-0015/2.2   стр. 3    D-0015 · раздел 2. Цена и порядок расчётов · пункт 2.2  (слова 1, смысл 2)
  2. D-0015/3.1   стр. 4    D-0015 · раздел 3. Ответственность · пункт 3.1  (слова 3, смысл 1)
  …
  —  D-0015/преамбула  стр. 1  D-0015 · преамбула  (добавлена правилом)

Получено: код 1d241f9; модель qwen3.6-27b-4bit, подсказка 09.1; поиск bge-m3, реранкер bge-reranker-v2-m3; отрывков 8, кандидатов 30, rrf_k 60, реранкер читает 30
```

Другие итоги — та же форма без блока утверждений:

```text
Вопрос в D-0015 — в документах ответ не найден, 9,2 с
Вопрос в D-0015 — подтверждённого ответа нет: ни одна из 2 цитат не найдена, 21,0 с
Вопрос по всем договорам — ошибка ответа модели: ответ не по форме после 3 попыток, 40,1 с
```

При `unconfirmed` неподтверждённые утверждения печатаются с пометкой «цитата
не найдена» (или «нет цитаты»); при нуле найденных отрывков вместо списка — «Просмотрено:
отрывков не найдено». Строки предупреждений поиска (`! …`) — сразу после первой строки,
как у `search`.

### `--json` — один объект

```json
{
  "question": "…", "document_id": "D-0015", "outcome": "answered",
  "claims": [
    {"text": "…", "quote": "…", "named_clause": "D-0015/3.2", "status": "confirmed_elsewhere",
     "clause_id": "D-0015/3.1", "quote_text": "…", "pages": [4], "from_retry": false}
  ],
  "shown": [
    {"clause_id": "D-0015/2.2", "label": "…", "first_page": 3, "last_page": 3,
     "search_place": 1, "word_place": 1, "vector_place": 2, "fused_place": 1,
     "added_by_rule": false}
  ],
  "retried": true, "not_found_first": 2, "not_found_final": 1, "failure": null,
  "warnings": [], "seconds": 18.4,
  "provenance": {"code_version": "1d241f9", "llm_model": "qwen3.6-27b-4bit",
    "prompt_version": "09.1", "embedding_model": "bge-m3",
    "reranker_model": "bge-reranker-v2-m3", "passages": 8, "candidates": 30,
    "rrf_k": 60, "rerank_candidates": 30}
}
```

Коды: 0 — `answered`, `unconfirmed`, `not_found`; 1 — `failed` (объект выводится
и при `--json`) и ошибки пользователя; 2 — окружение.

## `scripts/quickstart_answers.py --questions ФАЙЛ` (замер, R-10)

Только на ноутбуке: все три модели запущены. Каждый вопрос задаётся в своём договоре
(`ask` с `--document`). Полные ответы — в файл рядом с файлом вопросов, его читает
только аналитик. Печать и сводка — только числа и идентификаторы (FR-012), их можно
прислать агенту:

```text
Б4. Замер ответов: 24 вопроса (с ответом 16, без ответа 8), ошибок в наборе 1
  версия кода: 1d241f9
  модели: ответ qwen3.6-27b-4bit (подсказка 09.1), поиск bge-m3, реранкер bge-reranker-v2-m3
  настройки: отрывков 8, кандидатов 30, rrf_k 60, реранкер читает 30

  №   договор   пометка   итог          подтв. / не найд.   повтор   время, с
  1   D-0015    answer    answered      2 / 0               нет      14,2
  2   D-0007    none      not_found     0 / 0               нет       9,8
  3   D-0031    answer    unconfirmed   0 / 2               да       31,5
  4   D-0099    —         ошибка в наборе: договор не найден

                         с ответом (16)   без ответа (8)
  answered               13               1
  unconfirmed            1                0
  not_found              2                7
  failed                 0                0
  отказов на «none»                       7 из 8 (88%)

  время: медиана 15,1 с, наибольшее 41,0 с
  повторная проверка цитат: проверено 29, не найдено 0
  повторов запроса: 3

Ответы для оценки: …/questions/answers-b4-20261127-101500.txt (только для вас — содержит текст договоров)
Сводка сохранена: …/questions/answers-b4-summary-20261127-101500.txt (её можно прислать агенту)
```

Числа в примере — образец формы, не замер.

Коды: 0 — замер выполнен (даже с ошибками в наборе и итогами `failed`); 1 — нет файла,
файл не TOML, нет ни одного вопроса, у вопроса нет `text`, `document` или `expected`
из двух значений; 2 — модель недоступна.
