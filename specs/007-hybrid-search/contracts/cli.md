# CLI: поиск (фича 08)

Как у `index` и `passage` ([фича 07](../../006-passages-and-indexes/contracts/cli.md)):
переменные окружения, `--json`, коды выхода (0 — успех, 1 — ошибка пользователя,
2 — ошибка окружения, 130 — прервано). Решения — в [research.md](../research.md).

## `docreader search "ЗАПРОС" [--document ID] [--no-rerank] [--results N] [--json]`

Ищет отрывки по словам и по смыслу, сливает списки и пересортировывает реранкером.

- `--document D-0015` — только отрывки этого договора (R-5). `--no-rerank` — без
  реранкера на этот запуск (иначе — `[reranker] enabled`). `--results N` — вместо
  `[search] results`.
- Проверки до поиска, по порядку (R-10); на первой неудаче — сообщение и код:

  | Случай | Сообщение | Код |
  |---|---|---|
  | пустой запрос | «Пустой запрос — введите слова для поиска» | 1 |
  | `--results` вне 1…`rerank_candidates` | «--results: целое от 1 до 30» | 1 |
  | нет такого договора | «Нет документа D-0099 (список: docreader list)» | 1 |
  | у договора нет отрывков | «Отрывков нет: выполните docreader index D-0015» | 1 |
  | отрывки договора устарели | «Отрывки устарели: текст или разбор изменились — выполните docreader index D-0015» | 1 |
  | ни одного актуального отрывка | «Индексы пусты — выполните docreader index» | 1 |
  | нет векторов модели `[embedding] model` | «Индекс по смыслу построен другой моделью (нет векторов bge-m3) — выполните docreader index --all или укажите [embedding] model» | 2 |
  | модель поиска недоступна / FORBID | как у `index` (фича 07) | 2 |
  | реранкер включён и недоступен | «Реранкер недоступен по адресу http://127.0.0.1:8082/v1 — запустите его или выполните поиск с --no-rerank» | 2 |
  | реранкер включён, FORBID | «На этой машине реранкер не запускается (DOCREADER_FORBID_MODELS)» | 2 |

- Реранкер ответил ошибкой или не по форме во время поиска — «Реранкер ответил
  не по форме: 29 оценок на 30 отрывков — поиск остановлен», код 2, результатов нет
  (FR-005).
- Ни одного результата — «Ничего не найдено», код 0.

Текстовый вывод содержит текст договоров (FR-013): на реальных договорах его
не присылают агенту.

```text
Запрос в D-0015, реранкер bge-reranker-v2-m3 — 8 из 30 кандидатов (по словам 27, по смыслу 30), 1,8 с
! не проиндексированы или устарели 2 договора — выполните docreader index

1. D-0015/2.2.1  стр. 4–5  оценка 7.312  (слова 1, смысл 2, слияние 1)
   D-0015 · раздел 2. Цена и порядок расчётов · пункт 2.2.1
   Покупатель оплачивает товар в течение …

2. D-0015/2.3  стр. 5  оценка 3.004  (слова 4, смысл —, слияние 6)
   …
```

Без реранкера — нет «оценки», место = место слияния. Текст отрывка печатается
целиком, с отступом.

`--json` — один объект:

```json
{
  "query": "…", "document_id": "D-0015", "reranked": true,
  "embedding_model": "bge-m3", "reranker_model": "bge-reranker-v2-m3",
  "word_candidates": 27, "vector_candidates": 30, "seconds": 1.8,
  "warnings": ["не проиндексированы или устарели 2 договора — выполните docreader index"],
  "hits": [
    {"place": 1, "clause_id": "D-0015/2.2.1", "label": "…", "text": "…",
     "first_page": 4, "last_page": 5, "word_place": 1, "vector_place": 2,
     "fused_place": 1, "rerank_score": 7.312}
  ]
}
```

## `scripts/quickstart_search.py --questions ФАЙЛ [--json]` (замер, R-11)

Только на ноутбуке: модель поиска и реранкер запущены. Каждый вопрос ищется в договоре
своего ответа дважды — без реранкера и с ним — с 30 результатами. Вывод — только числа
и идентификаторы (FR-012), его можно прислать агенту:

```text
Б3. Замер реранкера: 18 вопросов, ошибок в наборе 1
  версия кода: 1d241f9
  модели: поиск bge-m3, реранкер bge-reranker-v2-m3
  настройки: кандидатов 30, rrf_k 60, реранкер читает 30

  №   ответ            без реранкера   с реранкером   время, с
  1   D-0015/2.2.1     1               1              0,21 / 1,62
  2   D-0007/4.1       6               2              0,19 / 1,48
  3   D-0031/9.3       —               4              0,20 / 1,71
  4   —                ошибка в наборе: нет отрывка D-0031/99.1

                       без реранкера   с реранкером
  на первом месте      9 из 17 (53%)   12 из 17 (71%)
  в первых пяти        14 из 17 (82%)  16 из 17 (94%)
  время: медиана       0,20 с          1,60 с
  время: наибольшее    0,31 с          2,40 с

Решение (FR-014): оставить реранкер включённым — в первых пяти 16 против 14, медиана 1,60 с ≤ 10 с
Сводка сохранена: …/questions/search-b3-summary-20261125-101500.txt (её можно прислать агенту)
```

Числа в примере — образец формы, не замер.

Коды: 0 — замер выполнен (даже с ошибками в наборе); 1 — нет файла, файл не TOML,
нет ни одного вопроса; 2 — модель поиска или реранкер недоступны.
