Окружение, коды завершения, формат идентификатора и сообщений об ошибках — как

## Настройки

Новый раздел `$DOCREADER_DATA_DIR/settings.toml` (ключи и значения по умолчанию —
[data-model.md](../data-model.md#настройки)):

```toml
[reading]
header_band = 0.1               # полоса сверху и снизу страницы для колонтитулов
header_min_share = 0.5          # колонтитул — больше чем на половине страниц
header_min_pages = 3
non_russian_min_letters = 3     # кириллические буквы вне русского алфавита
unreadable_min_letter_share = 0.6
unreadable_max_bad_share = 0.05
unreadable_max_vowelless_share = 0.4
column_min_lines = 3
column_min_gap = 20.0           # pt
column_gap_tolerance = 15.0     # pt
rotated_min_angle = 5.0         # градусы
```

Неизвестный ключ или значение вне диапазона — ошибка окружения (код 2), как для
разделов фичи 01.

## `docreader read [<ID>...] [--all] [--label МЕТКА] [--json]`

Читает документы и сохраняет результат (FR-001…FR-009, FR-012…FR-018).

| Вызов | Какие документы |
|---|---|
| `read` | этап `reading` в состоянии `pending` или `failed` |
| `read D-0003 D-0007` | указанные, в любом состоянии |
| `read --all` | все документы реестра |

`--all` вместе с идентификаторами — ошибка пользователя (код 1). Неизвестный
идентификатор — код 1, ничего не прочитано. Нечего читать — «Нечего читать: все
документы прочитаны (перечитать: docreader read --all)», код 0.

Создаёт запуск `run` (`stage = 'reading'`, настройки `[reading]`, версия словаря),
документы читаются по одному, каждый в своей транзакции. Читается копия из папки
данных, в режиме только чтения. Ошибка одного документа — состояние `failed`
с причиной, остальные продолжаются. Ctrl-C — текущий документ откатывается,
печатается частичный отчёт, код 130.

Вывод:

```
Чтение, запуск 42: 3 документа
D-0001  24 стр.  готово
D-0002  12 стр.  требует просмотра: стр. 11: скан, не прочитана; стр. 12: возможно, не русский текст
D-0003   3 стр.  ошибка: файл копии не найден — проверьте docreader verify D-0003
Текст изменился, следующие этапы сброшены: D-0001
Итого: готово 1, требует просмотра 1, ошибка 1
```

Код 0, если команда выполнена (документы с ошибкой видны в выводе, как у `add`).

JSON (`--json`): `{run_id, documents: [{id, pages, state, reason, text_changed,
flags: {code: [страницы]}}], totals: {done, needs_review, failed}}`.

## `docreader text <ID> [--page N] [--find ФРАЗА] [--json]`

Показывает прочитанный текст (сценарий 1.2, FR-003, FR-004). Документ не прочитан —
«Документ D-0001 ещё не прочитан — выполните docreader read D-0001», код 1.

- без ключей — очищенный текст документа; перед каждой страницей строка
  `── стр. N ──` и её флаги;
- `--page N` — строки страницы N по порядку: номер строки, роль, колонка/ячейка,
  текст; флаги с причинами; признак таблицы. Номер вне диапазона — код 1;
- `--find ФРАЗА` — все вхождения фразы (после приведения знаков R-5) в очищенном
  тексте и в вынесенных элементах: позиция в тексте, страница, номер строки,
  прямоугольник, роль (`body` или `header`/`footer`/`page_number`). Ничего не найдено —
  «Не найдено», код 0.

JSON: `{id, pages: [{page, rotation, has_table, flags: [{code, reason}],
lines: [...]}]}` для `--page`; `{id, phrase, matches: [{start, end, page, line,
bbox, role}]}` для `--find`.

## `docreader read-report [--csv [ПУТЬ]] [--json]`

Отчёт о чтении (сценарий 5, FR-011). Только по документам, у которых этап `reading`
не в `pending`.

```
ID      Имя              Стр.  Прочит.  Скан  Распозн.  Нечит.  Не рус.  Пустые  Порядок  Таблицы  Состояние
D-0001  dogovor_01.pdf     24       24     0         0       0        0       0        0        2  готово
D-0002  dogovor_02.pdf     12       11     1         0       0        1       0        0        0  требует просмотра
Итого                      36       35     1         0       0        1       0        0        2
```

«Прочит.» — страницы, давшие хотя бы одну строку; остальные столбцы — число страниц
с флагом. Страница с несколькими флагами считается в каждом.

`--csv` — то же в CSV (UTF-8 с BOM, разделитель `;`, research R-11); без пути —
`$DOCREADER_DATA_DIR/reports/reading-<дата-время>.csv`; печатается путь к файлу.
Текст договоров в отчёт не попадает.

## Изменения в существующих подкомандах

- `list` и `show` уже показывают состояние этапа «Чтение» (фича 01) — без изменений.
- `remove` — каскадом удаляет `page_text`, `page_flag`, `document_text`, `text_span`.
- `reclassify` — как и прежде, при изменении вида страниц сбрасывает все этапы
  документа, включая `reading`, в «ожидает»; следующий `read` без аргументов
  перечитает такие документы.
