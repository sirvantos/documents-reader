# Contract: командная строка `docreader`, распознавание (фича 13)

**Дата**: 2026-11-19 · **План**: [../plan.md](../plan.md) · **Модель данных**: [../data-model.md](../data-model.md) · **Интерфейс движка**: [engine.md](engine.md)

Окружение, коды завершения, формат идентификатора и сообщений об ошибках описаны
в [контракте фичи 01](../../001-document-intake/contracts/cli.md). Новые подкоманды
устроены по образцу `read`/`read-report` [фичи 03](../../002-pdf-text-reading/contracts/cli.md).
Текст договоров печатают только `text` (как раньше) и `recognize-eval --diff`.
Их вывод предназначен только для терминала аналитика.

## Настройки

Новый раздел в `$DOCREADER_DATA_DIR/settings.toml`. Ключи и значения
по умолчанию — в [data-model.md](../data-model.md#настройки).

```toml
[recognition]
engine = "tesseract"          # по умолчанию (замер 2026-11-20); пусто — движок не выбран
dpi = 300
try_rotations = true
page_min_quality = 0.90       # порог флага low_recognition_quality (замер 2026-11-22)
line_min_confidence = 0.60
max_low_line_share = 0.20
blank_max_ink_share = 0.003   # без строк и меньше — «пустая», иначе «текст на скане не найден»
model_dir = ""
```

Неизвестный ключ, значение не того типа или вне диапазона — ошибка окружения
(код 2). Неизвестное имя в `engine` — тоже код 2, с перечнем известных имён.

## `docreader recognize [<ID>...] [--all] [--pages N[-M]] [--force] [--label МЕТКА] [--json]`

Распознаёт страницы-сканы и сохраняет результат по каждой странице
(FR-001…FR-008, FR-011…FR-016).

| Вызов | Документы | Страницы |
|---|---|---|
| `recognize` | этап `recognition` не `done` или есть страница-скан без успешного результата | без успешного результата |
| `recognize D-0003 D-0007` | указанные | без успешного результата |
| `recognize --all` | все документы реестра | без успешного результата |
| `--force` (к любому вызову выше) | те же | все страницы-сканы заново |
| `recognize D-0003 --pages 3-5` | ровно один | только указанные, заново |

Ошибки пользователя (код 1). В этих случаях ничего не распознаётся:

- `--all` указан вместе с идентификаторами;
- `--pages` без идентификатора или с несколькими: «--pages указывается для одного
  документа»;
- страницы нет в документе: «В документе D-0003 нет страницы 9 (страниц: 5)»;
- страница не скан: «Стр. 2 документа D-0003 — не скан (вид: готовый текст);
  распознаются только страницы-сканы»;
- идентификатор не найден.

Если распознавать нечего, команда печатает «Нечего распознавать: все страницы-сканы
распознаны (заново: docreader recognize --all --force)» и выходит с кодом 0.
Документ без страниц-сканов получает `done` без загрузки движка, тоже с кодом 0.

Ошибки окружения (код 2) останавливают запуск, уже сохранённые страницы остаются:

- `engine` не задан: «Не выбран движок распознавания — укажите [recognition]
  engine в settings.toml (выбор — замером, quickstart Б1)»;
- движок запрещён на этой машине: «На этой машине движок распознавания
  не запускается (DOCREADER_FORBID_MODELS)»;
- движок не установлен или нет файлов модели: подсказка с командой установки
  на ноутбуке ([engine.md](engine.md)).

Запуск создаёт запись `run`: `stage = 'recognition'`, в `model` — движок и его
версия, в `settings` — раздел `[recognition]`. Копия файла открывается только
для чтения. Каждая страница пишется в своей транзакции. После каждой страницы
в stderr выводится строка прогресса: `D-0003 стр. 87 (1/52)  3,8 с` — номер
страницы, затем её место среди страниц этого запуска и их число. Ctrl-C откатывает
текущую страницу; команда печатает частичный отчёт и выходит с кодом 130.
Следующий `recognize` без аргументов продолжит с первой несохранённой страницы.

Вывод (stdout):

```
Распознавание, запуск 57 (tesseract 5.5.0 rus 4.1.0, 300 dpi): 3 документа
D-0003  42 скана  распознано 42  ошибок 0  низкое качество 3  без текста 1  пустых 2  412 с  готово
D-0004   0 сканов                                                                   готово
D-0005  52 скана  распознано 51  ошибок 1  низкое качество 0  без текста 0  пустых 0  530 с  требует просмотра: стр. 17: ошибка распознавания — RuntimeError: …
Чтение сброшено (распознанный текст изменён): D-0003, D-0005 — выполните docreader read
Итого: страниц 93, распознано 92, ошибок 1, низкое качество 3; 942 с, в среднем 10,1 с/стр.
```

Счётчики «низкое качество», «без текста» и «пустых» считаются по сохранённым
оценкам и текущим порогам функцией `quality.recognition_flags`, то есть так же,
как их потом поставит чтение. Код завершения 0, если команда выполнена; документы
с ошибкой видны в выводе.

JSON (`--json`):

```text
{run_id, engine, engine_version, dpi, interrupted,
 documents: [{id, scan_pages, recognized, errors, state, reason, reading_reset,
              seconds, flags: {low_recognition_quality: [стр.], scan_no_text: [стр.], empty: [стр.]},
              pages: [{page, turn, quality, ink_share, lines, seconds, result_sha256,
                       changed, error}]}],
 totals: {pages, recognized, errors, seconds, flags: {…}}}
```

В `pages` — только страницы, распознанные в этом запуске. `changed` показывает,
изменился ли отпечаток страницы. Текста строк в JSON нет.

## `docreader recognize-report [--review] [--csv [ПУТЬ]] [--json]`

Отчёт о распознавании (US7, FR-018). В отчёт входят только документы
со страницами-сканами. Флаги считаются по сохранённым оценкам и текущим порогам.
Таких документов нет — «Нет документов со страницами-сканами», код 0; пустой список
на просмотр — «Нет страниц на просмотр».

```
ID      Имя             Сканы  Распозн.  Ошибки  Низк. кач.  Без текста  Пустые  Ср. оценка  Время, с  Состояние
D-0003  dog_03.pdf         42        42       0           3           1       2        0,91       412  готово
D-0005  dog_05.pdf         52        51       1           0           0       0        0,94       530  требует просмотра
Итого                      94        93       1           3           1       2        0,93       942
```

- `--review` — список страниц на просмотр: страницы с `low_recognition_quality`,
  `scan_no_text` или ошибкой распознавания. Сначала ошибки, затем остальные
  от худшей оценки к лучшей:

  ```
  D-0005  стр. 17  ошибка распознавания  RuntimeError: …
  D-0003  стр. 31  низкое качество распознавания  оценка 0,52 < 0,90; 14 из 22 строк с уверенностью < 0,60
  D-0003  стр. 40  текст на скане не найден  строк нет, тёмных точек 4,1%
  ```

  Отметки «просмотрено» нет, флаг остаётся (уточнение 2).
- `--csv` — то же в CSV: UTF-8 с BOM, разделитель `;`, как у `read-report`. Если
  путь не указан, файл сохраняется в
  `$DOCREADER_DATA_DIR/reports/recognition-ГГГГММДД-ЧЧММСС.csv` (с `--review` —
  `recognition-review-…`). Команда печатает «Отчёт сохранён: <путь>».
- JSON: `{documents: [{id, name, scan_pages, recognized, errors, flags: {…},
  mean_quality, seconds, state}], totals: {…}}`; с `--review` —
  `{pages: [{id, page, code, reason, quality}]}`; `code` — `recognition_error`
  (`reason` — текст ошибки), `low_recognition_quality` или `scan_no_text`.

Текста договоров в отчёте нет. Имя файла выводится так же, как в `read-report`.

## `docreader recognize-eval <ПАПКА> [--label МЕТКА] [--diff] [--json]`

Замер качества распознавания (US5, FR-017, research R-12). `ПАПКА` должна лежать
внутри `$DOCREADER_DATA_DIR`. Иначе команда завершается с кодом 1 и сообщением
«Папка замера должна лежать в папке данных (проверенные тексты — реальные данные)».

Что лежит в папке, описано в R-12: `pages/<ID>-p<NNN>.txt`, `control.csv`
и необязательный `flags.csv`. Если файл не разобран или ссылается на документ
или страницу не из реестра, команда выходит с кодом 1 и называет файл и номер
строки. Страница без распознанного результата не останавливает команду: она
попадает в список «не распознаны» и в долю не входит.

Вывод (только цифры):

```
Замер распознавания: 24 страницы из 11 документов; tesseract 5.5.0 rus 4.1.0, 300 dpi
Верных знаков: 98,6% (по страницам: мин. 93,1%, медиана 99,0%)
Реквизиты и числа без ошибок: 97,9% (ИНН 12/12, КПП 8/8, ОГРН 6/6, суммы 21/22, даты 30/31, пункты 64/65)
Контрольные строки: 96,0% (48 из 50)
Пропущено строк: 3; повторено строк: 0
Флаг «низкое качество»: верен в 85,0% (ложных 3, пропущено 3 из 40)
Не распознаны: нет
Результат сохранён: <папка данных>/reports/recognition-eval-20261120-0915.json
```

- `--diff` дополнительно печатает список расхождений с текстом: страница, что
  ожидалось, что распознано. Только для терминала аналитика.
- JSON: `{label, engine, engine_version, dpi, settings, pages: [{id, page,
  recognition_run_id, reading_run_id, chars, char_accuracy, values: {kind: [found,
  total]}, missing_lines, repeated_lines}], totals: {pages, documents, chars,
  char_accuracy, values: {kind: [found, total]}, values_share, missing_lines,
  repeated_lines}, control: {kinds: {kind: [found, total]}, found, total, share},
  flags: {checked, accuracy, false_positive, false_negative} | null,
  not_recognized: [{id, page}]}`; с `--diff` — ещё `diffs`. Список ненайденных
  контрольных строк (`control.missing`) и расхождения сохраняются в файл отчёта
  всегда, в JSON на stdout списка ненайденных нет.
- Без `flags.csv` строка флага: «Флаг «низкое качество»: нет (нет файла flags.csv
  или он пуст)».

## Изменения в существующих подкомандах

- **`list`**: новый столбец «Распозн.» перед «Чтение», в нём состояние этапа
  `recognition`.
- **`show <ID>`**:
  - в блоке «Этапы» добавляется строка «Распознавание: …»;
  - в блоке «Страницы» у распознанной страницы-скана выводится
    `распознано tesseract 5.5.0 rus 4.1.0, 300 dpi, 2026-11-20 09:15, оценка 0,93`
    (US1-4), у страницы с ошибкой — `ошибка распознавания: …`;
  - в JSON у страницы появляется `recognition: {engine, engine_version, dpi, turn,
    quality, ink_share, recognized_at, run_id, error} | null`.
- **`text <ID> --page N`**:
  - после флагов выводится `Источник: распознано (tesseract 5.5.0 rus 4.1.0,
    оценка 0,93)` или `Источник: текстовый слой PDF`;
  - у распознанных строк выводится уверенность (`0,96`);
  - в JSON у страницы появляется `source`, у распознанных строк — `confidence`.
- **`text <ID>`** без `--page` не меняется: флаги страниц он уже выводит.
- **`read`**: интерфейс прежний. Для распознанных страниц-сканов строки берутся
  из `page_recognition`. Нераспознанная страница получает `scan_unread` с причиной
  «распознавание не выполнено — docreader recognize D-…». Пороги флагов
  распознавания берутся из `[recognition]`. Документы, у которых `recognize`
  сбросил чтение (этап `pending`), `read` без аргументов прочитает заново.
- **`read-report`**: новые столбцы «Низк. кач.» и «Без текста».
- **`reclassify`**: как и раньше, сбрасывает все этапы, теперь включая
  `recognition`.
- **`remove`**: каскадом удаляет и `page_recognition`.
