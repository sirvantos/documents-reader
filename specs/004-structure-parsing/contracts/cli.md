# CLI: разбор структуры (фича 04)

Команды устроены по образцу `read` и `text` [фичи 03](../../002-pdf-text-reading/contracts/cli.md):
переменные окружения, `--json`, коды выхода (0 — успех, 1 — ошибка пользователя,
2 — ошибка окружения, 130 — прервано) те же. Решения — в [research.md](../research.md).

## `docreader parse [ID…] [--all] [--label МЕТКА] [--json]`

Разбирает прочитанные документы на части и пункты.

- Без аргументов — доступные документы, у которых этап `structure` в `pending`
  или `failed`. `--all` — все доступные. `ID…` — указанные; `--all` вместе с ID —
  ошибка пользователя.
- Доступен документ, у которого чтение `done` или `needs_review` и прочитана хотя бы
  одна страница. Указанный недоступный документ не трогается и попадает в вывод
  со строкой «пропущен» и причиной («не прочитан — выполните docreader read D-0001»).
- Нечего разбирать — строка «Нечего разбирать: все документы разобраны (заново:
  docreader parse --all)», код 0.

Текстовый вывод — строка на документ и итог; текста договоров нет:

```text
D-0001  готово             разделов 14, пунктов 212, стр. 1–38
D-0002  требует просмотра  разделов 12, пунктов 180, стр. 1–31 — повтор: 6 (стр. 9)
D-0003  пропущен           не прочитан — выполните docreader read D-0003
D-0004  ошибка             ошибка разбора: ValueError
Итого: разобрано 2, требует просмотра 1, ошибок 1, пропущено 1 (запуск 57)
```

`--json`:

```json
{
  "run_id": 57,
  "documents": [
    {"document_id": "D-0001", "state": "done", "reason": null,
     "sections": 14, "clauses": 212, "first_page": 1, "last_page": 38,
     "has_tail": true}
  ],
  "skipped": [{"document_id": "D-0003", "reason": "не прочитан — выполните docreader read D-0003"}],
  "totals": {"parsed": 2, "needs_review": 1, "failed": 0, "skipped": 1},
  "interrupted": false
}
```

`clauses` — число пунктов и подпунктов (записи `clause` вида `clause`).

Причина `failed` — только `ошибка разбора: <тип исключения>`; текст исключения
не выводится и не сохраняется (он может содержать текст договора; принцип I, FR-007).
Виды причин `needs_review` — research.md R-7.

## `docreader outline ID [--json]`

Оглавление разобранного документа: дерево записей по порядку.

```text
D-0001 — разбор от 2026-11-25 (запуск 57), готово
D-0001/преамбула                     стр. 1      Договор подряда № …
D-0001/1      1. Предмет договора    стр. 1
D-0001/1.1      1.1.                 стр. 1      Подрядчик обязуется выполнить …
D-0001/1.1.1      1.1.1              стр. 1–2    … [распознано]
—             страница 7 не прочитана
D-0001/реквизиты                     стр. 36–38  14. Адреса и реквизиты сторон …
```

- У каждой записи: идентификатор, номер в напечатанном виде с отступом по глубине,
  страницы, начало собственного текста (до 60 знаков, одна строка).
- Пометка `[распознано]` — в диапазоне страниц записи есть распознанная страница;
  пометка `[низкое качество распознавания]` — в нём есть страница с флагом
  `low_recognition_quality`.
- Непрочитанная страница — строка «страница N не прочитана» на своём месте.
- Первая строка — состояние этапа и причина, если `needs_review`.
- Ошибки: неизвестный документ; документ не разобран («Документ D-0001 не разобран —
  выполните docreader parse D-0001»); разбор устарел («Разбор устарел: текст изменён —
  выполните docreader parse D-0001»). Код 1.

`--json`: `{"document_id", "state", "reason", "run_id", "records": [{"id", "key",
"kind", "number_printed", "depth", "parent", "title", "section_number",
"section_title", "start", "end", "first_page", "last_page", "recognized", "low_quality",
"head"}],
"unread_pages": [7]}`.

## `docreader clause ИДЕНТИФИКАТОР [--own] [--json]`

Текст записи по идентификатору (`D-0001/5.2`, `D-0001/5`, `D-0001/преамбула`,
`D-0001/реквизиты`).

- По умолчанию — запись вместе со всеми вложенными записями по порядку; каждая
  начинается со своего номера с новой строки, так что видно, где кончается
  собственный текст записи. Для раздела — заголовок и все его пункты.
- `--own` — только собственный текст записи.
- Шапка: идентификатор, заголовок раздела, страницы (всей выведенной части),
  пометка о распознанных страницах.
- Ошибки: неверный вид идентификатора (пример вида в сообщении); записи нет
  («Пункт D-0001/5.9 не найден — оглавление: docreader outline D-0001»); документ
  не разобран; разбор устарел. Код 1.

`--json`: `{"id", "section_title", "first_page", "last_page", "recognized",
"records": [{"id", "number_printed", "depth", "start", "end", "text"}]}`.

## Что можно присылать агенту

Вывод `parse` (текстовый и `--json`): идентификаторы, числа, номера пунктов
и страниц, причины. Причины строятся только из номеров пунктов и страниц и вида
ошибки, без текста договора и текста исключений. Вывод `outline` и `clause` содержит текст договоров — его
агенту не присылать (принцип I).
